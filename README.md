# Here's some fun info on American Kestrels:
# - American kestrels are the smallest falcon species in North America, roughly the size of a mourning dove
# - They are expert hunters that can hover in place while scanning the ground for insects, mice, and lizards
# - These colorful birds are cavity nesters, meaning they rely on old woodpecker holes, tree hollows, and man-made nest boxes to raise their young.
